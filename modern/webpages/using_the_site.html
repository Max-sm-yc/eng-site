How to use the Site

This is very important.

To navigate through this site use the navigation bar on the left. If you are using a browser other than IEexplorer you may need to download an IEexplorer plug-in for the site to operate properly. If at any time you want to go to the home page or the first page of any section you can click directly on the corresponding button, or hover you mouse pointer over the button, and a more in-depth table of contents will appear on its right.

 

This site requires activex for the interactive content and animations to be displayed properly. Click on the button as shown.

As you go through this site you will see the image below many times. It will be underneath text. If you click on it you hear audio content of the text it follows.

In this website there are many interactive puzzles. In one type of puzzle you will be presented with an object and asked to draw a particular view of the object. You can draw it in the flash box with your mouse pointer. Play around with the puzzle below and discover how to erase lines and how to change the colour of lines!

 

In these puzzles the pictures of the objects you must draw are in fact animations! To operate the flash animations and interactive content, press the play button on the animation controls. You should draw your image solution in the flash box, and then follow the steps mentioned above to compare your answer to the animation.

 

If you do not have the flash player, it can be downloaded for free from the following address:

http://www.adobe.com/products/flashplayer/

Another image that you will see a lot of is the edrawing symbol below. Edrawing is a free software package that allows you to view edawing files on my website. The software can be downloaded from this address:

http://www.solidworks.com/pages/programs/eDrawings/e2_downloadcheck.html

If you click on the symbol a new web page will open containing an object. You are able to rotate the object around with your mouse.

 

If you press the cross section button you will be able to take a Sectional view of the object (we will discuss Sectional views later in this site). The cross section button becomes accessible if you click View, UI mode, Complete.

Another important symbol in my site is the animation symbol. If you click this symbol you will be able to open a high quality .avi file. This file can be played in windows media player. The file it will open is generally a solution to a question, but it can also be a link to a higher definition movie than the animated image on the page.

 

The teacher and student resources require adobe pdf reader to be viewed and can be downloaded from this address:

http://www.adobe.com/products/acrobat/readstep2.html

Now let's get to the site!
